# Driving Behavior Research App

An Android app built using Unity and C# for behavioral research at USF’s EnCoDe Lab. This app dynamically adjusts car music volume based on the vehicle’s speed, designed to study the impact of auditory stimuli on driver behavior.

## 🚀 Features
- Real-time GPS-based speed tracking
- Fetches speed limit data using OpenStreetMap
- Mutes/unmutes music based on speed violations
- Logs trip data for post-analysis
- Simple UI inspired by Google Maps speedometer

## 🔧 Tech Stack
- Unity (C#)
- OpenStreetMap API
- Android SDK (via Unity)
- Git for version control

## 🧠 Research Context
This application is part of a study conducted by the EnCoDe Lab at USF to explore the influence of music volume on driving behavior.
